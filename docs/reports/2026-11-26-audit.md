## Проверки

Локально: Linux, Python 3.12; отдельное venv, зависимости из requirements-dev.txt.
`python -m pytest -q tests --junitxml=artifacts/tests.xml`: **63 passed**.
`python -m pip check`: no broken requirements. Compileall всех пяти разделов:
успешно. CLI basic_evaluation, bias_detection, safety_guardrails завершаются успешно;
ни один из этих CLI прогонов не вызывает provider API.

RAG tests используют настоящий FAISS с локальными deterministic embeddings.
ReAct tests используют реальный AgentExecutor и FakeListLLM; graph tests —
настоящий StateGraph с fake node chains. Advanced reranker и media SDK responses
подставлены. Эти проверки проверяют передачу данных и контрактов, не quality.

В каждом тесте исходящие socket connections заблокированы; provider keys удалены
из тестового окружения. Imports дополнительно запрещают OpenAI/ChatOpenAI client
construction и NLTK downloads. Тесты не тратят provider credits.

CI: Python 3.11/3.12, pip check, compileall, вся suite; artifact
`offline-python-*` содержит JUnit XML и resolved requirements. Локальная среда:
[2026-11-26-python312-environment.txt](2026-11-26-python312-environment.txt).
Это snapshot для аудита, не универсальный cross-platform lockfile.

## Ограничения и дальнейшая работа

- Live Qwen/OpenAI/Cohere API, доступность model IDs и реальные ответы не проверены.
  Название qwen-skills не является evidence of Qwen validation.
- Audio/image/moderation API относятся к отдельным провайдерским продуктам;
  OpenAI-compatible chat endpoint не гарантирует их поддержку.
- Legacy LangChain cohort сохранена ради воспроизводимого учебного контракта;
  переход на 1.x и отдельный vulnerability/dependency audit — следующая задача.
- Requirements ограничивают major/minor, но transitive dependency lock отсутствует.
  Две CI-версии Python могут разрешить разные допустимые версии пакетов.
- SQL read-only защищает от изменения, но не от чтения разрешённой БД: caller
  обязан выбрать отдельную allowlisted БД. SQLite limits — не process sandbox.
- AST calculator ограничен явно перечисленной математикой; arbitrary Python
  и неограниченные вычисления намеренно исключены.
- Bias metrics, prompt optimizer и regex guardrails остаются учебными эвристиками.
  Слова Safe/Acceptable в выводе demo не доказывают юридическую/этическую или
  adversarial устойчивость. Нужен отдельный evaluation protocol.
- При скачивании изображений URL должен происходить из доверенного источника;
  downloader не следует публиковать как универсальный proxy для пользовательских URL.
- File-extension MIME не валидирует содержимое изображения. Pydub требует отдельной
  установки и codecs; реальные audio chunks не проверялись.
- LangGraph выдаёт pending deprecation warning serializer allowlist; тесты проходят,
  checkpointer/persistent graph state в этом примере не используется.
- Изменение SQL API на read-only, Unknown format -> ValueError и schema validation
  являются намеренными изменениями поведения; команды README обновлены.
