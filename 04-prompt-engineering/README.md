# ✍️ Навык 4: Advanced Prompt Engineering

## Что это?

**Prompt Engineering** — это искусство создания эффективных промптов для получения желаемых результатов от AI-моделей.

## Почему это важно?

- ✅ **Качество ответов**: правильные промпты дают более точные и релевантные ответы
- ✅ **Эффективность**: сокращение количества итераций и токенов
- ✅ **Контроль**: управление поведением модели, форматом вывода
- ✅ **Снижение затрат**: оптимизированные промпты требуют меньше ресурсов

## Ключевые техники

### 1. Chain-of-Thought (CoT)
Пошаговое рассуждение для сложных задач:
```
Решите задачу шаг за шагом:
1. Сначала определите...
2. Затем проанализируйте...
3. Наконец, сделайте вывод...
```

### 2. Few-Shot Learning
Предоставление примеров для обучения модели:
```
Пример 1:
Вход: "Привет"
Выход: "Здравствуйте!"

Пример 2:
Вход: "Как дела?"
Выход: "Спасибо, хорошо!"

Теперь обработайте:
Вход: [новый запрос]
```

### 3. Constitutional AI
Задание правил и ограничений:
```
Вы - профессиональный ассистент. Следуйте этим правилам:
1. Всегда будьте вежливы
2. Не обсуждайте политику
3. Проверяйте факты перед ответом
```

### 4. Prompt Optimization
Итеративное улучшение промптов на основе результатов.

## Структура проекта

- `basic_prompts.py` - базовые техники промптинга
- `chain_of_thought.py` - пошаговое рассуждение
- `few_shot_learning.py` - обучение на примерах
- `prompt_optimizer.py` - оптимизация промптов
